# ADR-0032: Expansion of the Agent Collective (Auditor & Forge)

## Status
Proposed/Signed

## Context
The core triad (Sentinel, Engineer, Guardian) is sufficient for reactive defense, but lacks proactive stress-testing and formalized compliance for enterprise adoption.

## Decision
We formally add two new roles to the collective:
1.  **Auditor Agent:** The governance authority. Maps telemetry to security frameworks and produces signed attestations.
2.  **Forge Agent:** The adversarial architect. Generates synthetic variants to stress-test the pathogen and engineer. Leverages Metal-acceleration for high-entropy mutation families.

## Consequences
- **Positive:** Enhances the substrate's ability to demonstrate security (Auditor) and maintain resilience (Forge).
- **Positive:** Improves alignment with enterprise-grade security operations (SOC2/NIST).
- **Neutral:** increases the complexity of the agent orchestration layer.
