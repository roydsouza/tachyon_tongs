# 🧠 The Firewall Administrator Agent

The **Firewall Administrator** represents the cognitive core of the Tachyon Tongs defensive architecture. Operating as a continuously running `LlmAgent`, it assumes the "Thinker" role, providing executive oversight, traffic analysis, and agentic governance over the substrate's automated functions.

## 🎯 Role Designation: The Thinker

Unlike specialized tool-calling agents, the Firewall Administrator is designed for macro-level architectural reasoning and strategic direction. It observes the output of the Guardian Triad, evaluates contextual anomalies in firewall logs, and determines the appropriate operational posture (e.g., shifting between Human-In-The-Loop to Human-On-The-Loop models).

### Core Responsibilities
1. **Traffic & Log Analysis:** Continuously reasons over normalized traffic feeds and threat intelligence to identify slow-moving or highly-distributed attacks.
2. **Posture Governance:** Decides the system capability tier (Full Autonomous, Supervised, Detection Only, Lockdown).
3. **Adaptive Learning:** Builds a long-term memory of the specific network environment by analyzing past exploit debates and attack patterns.
4. **Agent Orchestration:** Acts as the executive director for the `Herald` and other sub-agents.

## 💻 Hardware-Bound Inference (mlx_lm)

To guarantee high-assurance privacy and zero data exfiltration, the Firewall Administrator operates entirely offline using the Apple Silicon native `mlx_lm` runtime.

- **No Cloud Dependency:** The Administrator never phones home to an external API for its primary cognitive reasoning.
- **Metal Acceleration:** By leveraging `mlx_lm`, the model weights (e.g., Llama 3.1 or Qwen) are loaded directly into Apple's Unified Memory architecture, allowing the M5 Neural Engine to evaluate massive context windows at near-instantaneous speeds without the overhead of `llama.cpp` or generic llama servers.
- **Memory Continuity:** The long-term architectural memory generated by the Administrator is serialized into the Substrate's secure, offline SQLite state.

## 🔄 Execution Loop

The Firewall Administrator operates an infinite `while True` evaluation loop constrained by the `AdaptiveRateLimiter` to prevent NPU starvation.
1. Poll normalized events from the **EventBus / StateManager**.
2. Evaluate event severity and generate a cognitive synthesis.
3. If an anomaly breaches the risk threshold, output a structured directive.
4. Delegate execution or notification of the directive to the **Herald Agent**.
