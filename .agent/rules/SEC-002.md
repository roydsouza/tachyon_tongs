# SEC-002: High-Assurance SDLC & Task Integrity

## Context
Tachyon Tongs is a high-assurance security substrate. Every modification must be traceable, verified, and cryptographically anchored.

## Rules
1.  **Task Synchronization**: `TASKS.md` must be updated *before* starting a task (marking it as `[/]`) and *immediately after* completion (marking it as `[x]`).
2.  **ADR-First Design**: Significant architectural or security changes MUST be preceded by a signed ADR in `docs/adr/`.
3.  **Test-Driven Agent Development (TDAD)**:
    - Every feature/fix must include a dedicated regression test suite.
    - All tests must pass (including the `smoke_test_plugins.py`) before the task is marked complete.
4.  **Forensic Verification**:
    - Edits to core files must be verified via `view_file` immediately after the tool call.
    - All modified artifacts must be re-signed using the `IntegrityManager`.
5.  **Clutter Avoidance**: Stale test files, mock data, and duplicate tasks must be purged immediately to prevent "State Drift."

## Enforcement
The agent must verify these steps in its `walkthrough.md` for every major phase.
