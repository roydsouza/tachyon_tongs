# SEC-002: Substrate Hardening & Fail-Closed Mandates

## Status
Active (Forensic Override)

## The Principle
To prevent the re-emergence of critical vulnerabilities (Mutant Lock, TOCTOU, Fail-Open defaults), the Tachyon Tongs substrate enforces 5 Absolute Prohibitions. Any violation is a CRITICAL FAILURE of the development cycle.

## 🚫 The 5 Absolute Prohibitions

1. **The Mutant Lock is DEAD**: NEVER re-implement the non-blocking `Mutant Lock` pattern. All integrity checks (Provenance, Signature, Policy) MUST be unconditional. If verification fails, the system MUST fail loud and refuse to proceed.
2. **Silent Exceptions are BANNED**: NEVER use `print()` or `pass` in a security-critical `except` block. You MUST use `logging.critical()` and re-raise the exception to trigger the substrate's fail-closed handlers.
3. **Test-Mode Constructor Params are FORBIDDEN**: NEVER add `rego_mock` or `allow_duplicates` parameters to class constructors (e.g., `SingularityPDP`). Test modes MUST be exclusively gated by the `TACHYON_TEST_MODE=1` environment variable.
4. **Fail-Open Defaults are PROHIBITED**: All policy engines (PDPs) and enforcement points (PEPs) MUST default to `DENY` or `EMPTY_LIST`. Permission MUST be explicitly granted.
5. **Fire-and-Forget Alerts are LEGACY**: All `emit_alert` calls in high-assurance paths must be inside a `try/except` block with a synchronous logging fallback to ensure that even if the alert bus stalls, the event is recorded.

## Mandatory Verification Ritual
Every code change to an agent or core enforcement file MUST be followed by:
1. `python3 scripts/calibrate_sbom.py`: To update the cryptographic provenance hashes.
2. `python3 scripts/forensics/resign_docs.py`: To re-anchor all task logs and audit trails.
