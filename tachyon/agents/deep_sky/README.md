# Deep Sky Observer: Out-of-Band Agent Template

> [!NOTE]
> This repository is currently a **placeholder**.

## Intent
`deep_sky_observer` is a template for building **Out-of-Band** agents that run independently (out-of-process) but discover and utilize Tachyon Tongs for secure execution.

### Characteristics:
- **Environment**: Runs in its own separate repository or machine.
- **Discovery**: Communicates with the Tachyon Substrate via the `tachyon_client` or the **MCP Gateway**.
- **Capabilities**: Uses `tachyon_safe_fetch` and `tachyon_safe_execute` to proxy risky operations through the substrate's protective Triad.
- **Autonomy**: Maintains its own lifecycle while benefiting from centralized "Systemic Paranoia" defense.
